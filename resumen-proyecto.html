Setup y configuración

Con Google API Key (modo automático)

  • La clave se guarda en localStorage en una key separada y no se borra al reconfigurar.
  • El usuario pega la URL del spreadsheet → "Detectar hojas" → llama a sheets.googleapis.com/v4/spreadsheets/{ID}.
  • Se listan todas las pestañas con:
    • Checkboxes para marcar cuáles son hojas de datos (por defecto: todas seleccionadas)
    • Radio para elegir cuál es la hoja PD (por defecto: ninguna)
  • Equipos: detecta automáticamente las pestañas "Resultados" y "Data" por nombre exacto.
  • Errores descriptivos para: archivo .xlsx, restricciones de referrer, API no habilitada, key inválida.

Sin Google API Key (modo manual / fallback)

  • Un campo URL por hoja (RawData obligatoria, PD opcional).
  • Validación post-fetch: parsea el CSV y verifica que retorne datos.
  • Detección de URLs invertidas (swap detection): si RawData devuelve presiones y PD devuelve salas, informa el error específico.

Schema de configuración (localStorage)

{
  // Salas
  rawDataSheetId,          // ID del spreadsheet de Google
  rawDataGid,              // gid único — modo manual (null en modo auto)
  rawDataSheets,           // [{title, gid}, …] — modo auto (null en modo manual)
  pdSheetId,               // null si no se configuró hoja PD
  pdGid,                   // null si no se configuró hoja PD

  // Equipos
  equipResultsSheetId, equipResultsGid,
  equipDataSheetId, equipDataGid,

  // IA
  anthropicApiKey,
  anthropicModel           // default: "claude-sonnet-4-6"
}

// Clave separada (no se borra con clearConfig):
localStorage['ensayos_google_api_key']

Informe IA (TextReport + report.js)

  • Requiere Anthropic API Key (opcional). Modelo configurable, default claude-sonnet-4-6.
  • Formato: acta de servicio compacta — ensayos ejecutados + salas, faltantes, conformes, no conformes, pendientes.
  • Si no hay hoja de equipos configurada, el prompt instruye explícitamente a no mencionarlos.
  • Llamada directa al API desde el browser con header anthropic-dangerous-direct-browser-access: true.

Pendientes / limitaciones conocidas

  • Requisito externo El spreadsheet debe ser Google Sheets nativo (no .xlsx) para la detección automática.
  • Sin git El proyecto no tiene repositorio git inicializado — no hay historial de versiones.
  • Sin backend La Anthropic API Key queda expuesta en el browser. Aceptable para uso interno/local.
  • Bundle size JS bundle ~638 kB minificado (Recharts + PapaParse). Sin code-splitting por ahora.
